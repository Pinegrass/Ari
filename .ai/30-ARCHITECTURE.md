# Architecture
Parent is Expo/React Native: navigation, screens/components, context/state/API clients and utilities are under `src/`; EAS/native config is at root; migrations/support under `supabase/`. `backend/` is a nested Flask/SQLAlchemy/PostgreSQL repository deployed by Railway with JWT auth, finance APIs, Tomo providers, RevenueCat/Razorpay and scheduled jobs. `aritomo-web/` is a nested Next.js/Supabase repository with backend token sync and Razorpay checkout. API URL, auth/token semantics, entitlement state and payment webhooks are critical cross-repo contracts. A parent commit does not record nested HEADs.
